# DocTools

Word ↔ PDF, document scanner, passport photos, photo editor and cropper. Everything runs on the device and works offline. Install it on an iPhone from Safari with **Share → Add to Home Screen**.

## Put it on GitHub Pages

1. On github.com, click **New repository**. Name it `doctools`, set it to **Public**, and click **Create repository**.
2. On the new repo page, click **uploading an existing file**.
3. Open the unzipped `doctools` folder, select **everything inside it** (not the folder itself), and drag it onto the upload page. Wait for every file to finish, then click **Commit changes**.
4. Go to **Settings → Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, Branch to **main** and folder to **/ (root)**, then click **Save**.
5. After 1–2 minutes your app is live at `https://YOUR-USERNAME.github.io/doctools/`

## Install on iPhone

1. Open that address in **Safari**.
2. Tap **Share** (square with arrow) → **Add to Home Screen** → **Add**.
3. While on Wi-Fi, use the Passport photo tab once so the AI model (about 55 MB) downloads. After that it all works offline.

Saving: tap Download and pick **Save Image** for photos or **Save to Files** for PDFs and Word files.

## Updating

Upload the changed files the same way. They replace the old ones. Then close and reopen the app on the phone, twice if needed, to pick up the new version.
